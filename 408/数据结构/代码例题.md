# 2025 年 408 · 第 41 题（数据结构算法设计，13 分）

## 题目

设有两个长度均为 $n$ 的一维整型数组 $A$ 和 $res$，对数组 $A$ 中的每个元素 $A[i]$，计算 $A[i]$ 与 $A[j]$（$0 \le i \le j \le n-1$）乘积的最大值，并将其保存到 $res[i]$ 中。

例如，若 `A[] = {1, 4, -9, 6}`，则得到 `res[] = {6, 24, 81, 36}`。

现给定数组 $A$，请设计一个时间和空间上尽可能高效的算法 `calMulMax`，求 $res$ 中各元素的值。函数原型为：

```c
void calMulMax(int A[], int res[], int n);
```

**要求：**
1. 给出算法的基本设计思想（4 分）
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释（7 分）
3. 说明你所设计算法的时间复杂度和空间复杂度（2 分）

## （1）基本设计思想

对固定的 $i$，能使 $A[i] \times A[j]$ 最大的 $A[j]$ 只可能是后缀 $A[i..n-1]$ 中的**最大值 $Max$ 或最小值 $Min$**：

- 若 $A[i] \ge 0$：最大乘积来自 $A[i] \times Max$；
- 若 $A[i] < 0$：最大乘积来自 $A[i] \times Min$（负负得正，越小的负数相乘结果越大）。

因此从==右向左扫描==，动态维护当前后缀（含 $A[i]$ 本身）的最大值 $Max$ 与最小值 $Min$，每个元素只处理一次。

知识点：数组、后缀极值、贪心。

## （2）C 语言实现

```c
void calMulMax(int A[], int res[], int n) {
    if (n <= 0) return;

    int Max = A[n - 1];
    int Min = A[n - 1];

    for (int i = n - 1; i >= 0; i--) {
        // 先更新后缀极值，使其包含 A[i] 自身（因为 j = i 合法）
        if (A[i] > Max) Max = A[i];
        else if (A[i] < Min) Min = A[i];

        // 根据 A[i] 的正负选择乘后缀最大值或最小值
        if (A[i] >= 0)
            res[i] = A[i] * Max;
        else
            res[i] = A[i] * Min;
    }
}
```

等价写法（直接取两者较大值）：

```c
int p1 = A[i] * Max;
int p2 = A[i] * Min;
res[i] = (p1 > p2) ? p1 : p2;
```

## （3）复杂度

- **时间复杂度：$O(n)$** —— 只需从后向前扫描一遍数组。
- **空间复杂度：$O(1)$** —— 仅使用常数个辅助变量。

## 易错点

- $j = i$ 也合法，故 $res[i]$ 至少包含 $A[i]^2$；例中 $res[2] = 81 = (-9) \times (-9)$ 正说明这一点。
- 这是"对每个 $i$ 求后缀乘积最大值"，**不是**"连续子数组乘积最大值"问题。
- 暴力 $O(n^2)$ 也能得正确结果，但不符合"尽可能高效"，最高只能得 5 分（第 2 问）。
- 注意内层 $j$ 应从 $i$ 开始；循环条件、函数名/数组名要与题面原型一致。
