
# 前置语法
> 读 408 算法代码的必备基础：`typedef`/`malloc`（结构体与动态内存）、引用与指针、数组、宏、布尔、运算符、输入输出。先吃透这一节，后面各章代码才能顺畅阅读。

## 1. typedef：给类型起别名
- 形式：`typedef 已有类型 新名字;`，**是类型的同义词，不创建新类型**
```c
typedef unsigned int uint;   // 此后 uint 与 unsigned int 完全等价
```
- **结构体别名（408 核心写法）**：
```c
typedef struct LNode {          // ① 标签(tag) 为 LNode 的结构体
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;             // ② 别名 LNode = struct LNode；③ 别名 LinkList = struct LNode *（这个*是跟在struct LNode后面的）
```
  - `LinkList L;` 等价于 `LNode *L;`（一个结构体别名，一个结构体指针别名）
  - 花括号内必须写 `struct LNode *next`：此时别名 `LNode` **尚未生效**，只能用标签自引用
  - 结构体**标签**与 typedef **别名**属于不同命名空间，可以同名
- **自引用结点必须有标签**：链表/树/图的结点要指向自身，不能用匿名结构体（匿名结构体无法引用自己）
- **typedef vs define（易错）**：
```c
typedef int *intptr;   intptr a, b;   // ✅ a、b 都是 int*
#define intptr int*    intptr a, b;   // ❌ 变成 int *a, b; b 是 int
```
  > 宏是**文本替换**，typedef 是**类型别名**；给指针类型起名务必用 typedef。

## 2. malloc：动态申请内存
```c
#include <stdlib.h>
void *malloc(size_t size);   // 参数是「字节数」，返回首地址(void*)，失败返回 NULL，内存不清零
```
- **408 教材写法（务必带强制转换）**：
```c
LNode *s = (LNode *)malloc(sizeof(LNode));
//      └ 强转成目标指针 ┘  └ 要分配的字节数 ┘
```
- **分配数组**：字节数 = 元素个数 × 单元素大小
```c
L.data = (ElemType *)malloc(InitSize * sizeof(ElemType));
```
- `sizeof` 是**运算符**不是函数，编译期求值；`sizeof(LNode)` 得到类型字节数
- **释放**：`free(s); s = NULL;`（只能释放动态内存、只能释放一次、不改变指针值故需手动置空）
```c
free(B);   // 如归并排序中释放辅助数组
```
- **常见错误**：忘记乘 `sizeof`、不检查返回值、free 后继续用、二次 free、忘记 free（内存泄漏）
- **相关函数**：`calloc`（分配并清零）、`realloc`（调整大小）

## 3. 引用 `&`、指针 `*` 与函数传参 ⭐
### 引用 `&`（C++ 特性，王道几乎每个函数都用）
```c
void f(SqList &L) { L.length = 0; }   // 形参 L 是实参的「别名」，改 L 即改实参
f(L);                                  // 调用时直接传对象本身
```
- 作用：让函数**直接修改实参**，且函数内用 `.`（不用 `->`）访问成员
- ⚠ 同一个符号 `&`，两种含义（看上下文）：
  - **声明/定义处**：`SqList &L` → **引用**
  - **表达式处**：`&x` → **取地址**（如 `scanf("%d", &x)`）
### 指针 `*`
```c
LNode *p;      // 声明：p 是「指向 LNode 的指针」
*p             // 表达式：解引用，取 p 所指的对象
&x             // 表达式：取 x 的地址
```
- 同理，`*` 在**声明处**表「指针类型」，在**表达式处**表「解引用」
- `NULL`（空指针）：`p == NULL` 表示 p 不指向任何对象；链表表尾、查找失败都返回/判断 `NULL`
### `.` 与 `->` 的区别（最常见笔误）
```c
LNode n;    n.data       // 结构体「变量」用 .
LNode *p;   p->data      // 结构体「指针」用 ->，等价于 (*p).data
```
### 三种传参方式对比
| 写法 | 调用 | 函数内访问成员 | 能否改实参 | 说明 |
| --- | --- | --- | --- | --- |
| `void f(SqList &L)` | `f(L)` | `L.length` | ✅ 能 | C++ 引用，王道最常用 |
| `void f(SqList *L)` | `f(&L)` | `L->length` | ✅ 能 | 指针，纯 C 风格 |
| `void f(SqList L)` | `f(L)` | `L.length` | ❌ 不能 | 值传递，拷贝一份 |
> [!warning] 口诀
> 想改实参就加 `&`（引用）或传 `&`（指针）；**`.` 配变量，`->` 配指针**。

## 4. 数组与结构体
### 数组
```c
int A[10];           // 10 个 int，下标 0 ~ 9
A[0] = 1;            // 第 1 个元素是 A[0]，不是 A[1]
int B[3][4];         // 二维数组（如邻接矩阵）
```
- **数组作函数参数会「退化」为指针**：
```c
void f(int A[], int n)   // 等价于 void f(int *A, int n)，A 只是一个地址
```
- 顺序表用 `L.data[i]` 访问第 i+1 个元素
### 结构体
```c
struct Student {          // 定义结构体
    int no;
    char name[20];
} s1, s2;                 // 定义时顺便声明变量
s1.no = 1;                // 用 . 访问成员
struct Student arr[10];   // 结构体数组
arr[0].no = 1;
```

## 5. 宏定义与常量
```c
#define MaxSize 100       // 宏：预处理阶段的文本替换，末尾不加分号
```

- 宏只是**文本替换**，没有类型检查

## 9. switch 多分支选择 ⭐
```c
switch (表达式) {              // 表达式必须是「整型/字符型/枚举」，不能是 float/字符串
    case 常量1:               // case 后必须是编译期常量（字面量、宏、const），且互不相同
        语句序列1;
        break;                // 跳出整个 switch；漏写会「贯穿」到下一个 case
    case 常量2:
        语句序列2;
        break;
    default:                  // 所有 case 都不匹配时执行（可省略，位置任意，一般放最后）
        语句序列;
}
```
- **表达式类型**：`int` / `char` / `enum`，**不能**是 `float`、`double`、字符串
- **case 常量**：必须是编译期常量（如 `1`、`'a'`、`#define` 的宏），且各 case 值不能重复
- **`break` 的作用**：跳出 switch。**漏写会「贯穿（fall-through）」**——继续执行下一个 case 的语句（有时是有意为之，见下例）
- **`default`** 分支：处理意外/非法输入，可放在任意位置（放最后最清晰）
- switch **只能判「相等」**；判断区间、范围、复合条件要用 `if-else if`
- 与之对比：分支少且离散用 `switch`（更清晰）；分支是范围/条件式用 `if-else`

**例 1：根据运算符分发（表达式求值常用）**
```c
int Calc(int a, char op, int b) {
    switch (op) {
        case '+': return a + b;
        case '-': return a - b;
        case '*': return a * b;
        case '/':
            if (b != 0) return a / b;
            return 0;                 // 除零保护
        default:
            return 0;                 // 非法运算符
    }
}
```

**例 2：有意贯穿——多个 case 共用同一段逻辑**
```c
switch (ch) {
    case ' ':
    case '\t':
    case '\n':                        // 空白字符统一处理（无 break 是故意的）
        count++;
        break;
    default:
        break;
}
```
> [!warning] 易错点
> ① `case` 后只能跟常量，不能跟变量（`case n:` ❌）；② 每个 case **结尾大多要 `break`**，忘写会意外贯穿；③ `switch(x)` 里的 x 不能是浮点/字符串；④ case 值不能重复。

| 语法                                | 含义              | 典型用途      |
| --------------------------------- | --------------- | --------- |
| `typedef struct X {...} X, *Ptr;` | 结构体及结构体指针别名     | 链表/树/图结点  |

| `类型 *p` / `p->成员`                 | 指针 / 箭头访问       | 链表、树、图    |
| `变量.成员`                           | 点号访问            | 结构体变量     |

# 一、线性表
## 1. 顺序表
### 结构定义
```c
#define InitSize 100
typedef struct {
    ElemType *data;      // 动态分配数组的指针
    int length, MaxSize; // 表长、最大容量
} SqList;
```
### 初始化
```c
void InitList(SqList &L) {
    L.data = (ElemType *)malloc(InitSize * sizeof(ElemType));
    L.length = 0;
    L.MaxSize = InitSize;
}
```
### 逆置（原地，时间 $O(n)$、空间 $O(1)$）
```c
// 顺序表原地逆置：首尾对称交换
void Reverse(SqList &L) {
    ElemType temp;
    for (int i = 0; i < L.length / 2; i++) {
        temp = L.data[i];
        L.data[i] = L.data[L.length - 1 - i];
        L.data[L.length - 1 - i] = temp;
    }
}
// 将区间 L.data[from..to]（闭区间）逆置
void ReverseRange(SqList &L, int from, int to) {
    ElemType temp;
    for (int i = 0; i < (to - from + 1) / 2; i++) {
        temp = L.data[from + i];
        L.data[from + i] = L.data[to - i];
        L.data[to - i] = temp;
    }
}
```
> [!tip] 逆置是「循环移位」的利器（408 经典大题）
> 将 $L[0..n-1]$ **循环左移 $p$ 位**（$0<p<n$），用**三次逆置**实现：
> ```c
> ReverseRange(L, 0, p - 1);     // ① 前 p 个逆置
> ReverseRange(L, p, n - 1);     // ② 后 n-p 个逆置
> ReverseRange(L, 0, n - 1);     // ③ 整体逆置
> ```
> **循环右移 $p$ 位**则把①②顺序对调（先整段、再分别）。
> 时间复杂度 $O(n)$、空间 $O(1)$，比「逐个移动」的 $O(pn)$ 高效得多。

## 2. 单链表
### 结构定义
```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```
### 头插法建立（$O(n)$，结果==与输入顺序相反==）
```c
void List_HeadInsert(LinkList &L) {
    L = (LinkList)malloc(sizeof(LNode));
    L->next = NULL;                    // 初始为空表
    int x;
    scanf("%d", &x);
    while (x != 9999) {                // 输入结束标志
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        s->next = L->next;
        L->next = s;                   // 插入到头结点之后
        scanf("%d", &x);
    }
}
```
### 尾插法建立（$O(n)$，结果与输入==顺序相同==）
```c
void List_TailInsert(LinkList &L) {
    L = (LinkList)malloc(sizeof(LNode));
    L->next = NULL;
    LNode *r = L;                      // r 始终指向表尾
    int x;
    scanf("%d", &x);
    while (x != 9999) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        r->next = s;
        r = s;
        scanf("%d", &x);
    }
    r->next = NULL;                    // 尾结点置空
}
```
### 后插（在 p 之后插入，$O(1)$）
```c
bool InsertNextNode(LNode *p, ElemType e) {
    if (p == NULL) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;                 // 先接后继，防断链
    p->next = s;
    return true;
}
```
### 前插（在 p 之前插入，$O(1)$：偷梁换柱）
```c
bool InsertPriorNode(LNode *p, ElemType e) {
    if (p == NULL) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->next = p->next;
    p->next = s;
    s->data = p->data;                 // 把 p 的数据挪到新结点
    p->data = e;                       // p 存新数据
    return true;
}
```
### ⭐就地逆置（头插法思想）
```c
void ReverseList(LinkList L) {         // 带头结点
    LNode *p = L->next, *r;
    L->next = NULL;                    // 断开头结点
    while (p != NULL) {
        r = p->next;                   // 暂存后继
        p->next = L->next;             // 头插
        L->next = p;
        p = r;
    }
}
```
### 快慢指针找中间结点
```c
LNode *FindMid(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;             // 一次走一步
        fast = fast->next->next;       // 一次走两步
    }
    return slow;
}
```
> [!important] 链表算法设计题常考
> 就地逆置、快慢指针找中间结点、判环并找入口、找公共结点、拆分奇偶、递增有序合并、删除倒数第 $k$ 个、删除重复元素。

## 3. 双链表
### 结构定义
```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```
### 在 p 之后插入 s
```c
bool DInsertNextNode(DNode *p, DNode *s) {
    if (p == NULL || s == NULL) return false;
    s->next = p->next;
    if (p->next != NULL) p->next->prior = s;   // 注意判空
    s->prior = p;
    p->next = s;
    return true;
}
```
### 删除 p 的后继结点
```c
bool DDeleteNextNode(DNode *p) {
    if (p == NULL || p->next == NULL) return false;
    DNode *q = p->next;
    p->next = q->next;
    if (q->next != NULL) q->next->prior = p;   // 注意判空
    free(q);
    return true;
}
```
## 4. 循环链表
- **循环单链表**：尾结点 `next` 指向头结点；判空 `L->next == L`
- **循环双链表**：头结点 `prior` 指向尾结点；判空 `L->next == L && L->prior == L`

# 二、栈和队列
## 1. 顺序栈
```c
typedef struct {
    ElemType data[MaxSize];
    int top;                           // 栈顶指针，指向栈顶元素
} SqStack;

bool Push(SqStack &S, ElemType x) {
    if (S.top == MaxSize - 1) return false;   // 栈满
    S.data[++S.top] = x;
    return true;
}
bool Pop(SqStack &S, ElemType &x) {
    if (S.top == -1) return false;            // 栈空
    x = S.data[S.top--];
    return true;
}
```
> 栈空 `S.top == -1`，栈满 `S.top == MaxSize - 1`，栈长 `S.top + 1`

## 2. 共享栈
两栈栈底分别置于数组两端，栈顶向中间延伸；**栈满条件** `top1 - top2 == 1`

```c
typedef struct LinkNode {
```

## 4. 循环队列（牺牲一个存储单元）
```c
typedef struct {
    ElemType data[MaxSize];
    int front, rear;                   // rear 指向队尾元素的下一个位置
} SqQueue;

bool EnQueue(SqQueue &Q, ElemType x) {
    if ((Q.rear + 1) % MaxSize == Q.front) return false;  // 队满
    Q.data[Q.rear] = x;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}
bool DeQueue(SqQueue &Q, ElemType &x) {
    if (Q.rear == Q.front) return false;                  // 队空
    x = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    return true;
}
```
> 队空 `Q.front == Q.rear`，队满 `(Q.rear + 1) % MaxSize == Q.front`，队长 `(Q.rear + MaxSize - Q.front) % MaxSize`
> 另有「设 size 成员」「增设 tag 标志」两种判满/判空方案，详见 [[408/数据结构/2.线性结构/5.队列.md]]

## 5. 链队列
```c
typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode;
typedef struct {
    LinkNode *front, *rear;            // 队首、队尾指针
} LinkQueue;
```
> 出队时需单独判断队列是否只剩一个元素；适用于元素数量频繁变化的场景，不存在队满

# 三、树与二叉树
## 1. 二叉树链式存储
```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```
## 2. 三种递归遍历（$O(n)$）
```c
void PreOrder(BiTree T) {              // 先序 NLR
    if (T != NULL) {
        visit(T);
        PreOrder(T->lchild);
        PreOrder(T->rchild);
    }
}
void InOrder(BiTree T) {               // 中序 LNR
    if (T != NULL) {
        InOrder(T->lchild);
        visit(T);
        InOrder(T->rchild);
    }
}
void PostOrder(BiTree T) {             // 后序 LRN
    if (T != NULL) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        visit(T);
    }
}
```
## 3. 中序非递归遍历（借助栈）
```c
void InOrderNonRec(BiTree T) {
    InitStack(S);
    BiTree p = T;
    while (p != NULL || !IsEmpty(S)) {
        if (p != NULL) {
            Push(S, p);
            p = p->lchild;             // 一路向左
        } else {
            Pop(S, p);
            visit(p);
            p = p->rchild;             // 转向右子树
        }
    }
}
```
## 4. 层次遍历（借助队列）
```c
void LevelOrder(BiTree T) {
    InitQueue(Q);
    BiTree p;
    EnQueue(Q, T);
    while (!IsEmpty(Q)) {
        DeQueue(Q, p);
        visit(p);
        if (p->lchild != NULL) EnQueue(Q, p->lchild);
        if (p->rchild != NULL) EnQueue(Q, p->rchild);
    }
}
```
## 5. 求树高 / 结点数 / 叶子数
```c
int TreeDepth(BiTree T) {              // 树高
    if (T == NULL) return 0;
    int l = TreeDepth(T->lchild);
    int r = TreeDepth(T->rchild);
    return (l > r ? l : r) + 1;
}
int NodeCount(BiTree T) {              // 结点总数
    if (T == NULL) return 0;
    return NodeCount(T->lchild) + NodeCount(T->rchild) + 1;
}
int LeafCount(BiTree T) {              // 叶子数
    if (T == NULL) return 0;
    if (T->lchild == NULL && T->rchild == NULL) return 1;
    return LeafCount(T->lchild) + LeafCount(T->rchild);
}
```
## 6. 判断完全二叉树（层次遍历 + 空结点标记）
```c
bool IsComplete(BiTree T) {
    if (T == NULL) return true;
    InitQueue(Q);
    EnQueue(Q, T);
    while (!IsEmpty(Q)) {
        DeQueue(Q, p);
        if (p != NULL) {               // 非空结点：左右孩子（含空）都入队
            EnQueue(Q, p->lchild);
            EnQueue(Q, p->rchild);
        } else {                       // 遇到空结点后，若还有非空结点则非完全
            while (!IsEmpty(Q)) {
                DeQueue(Q, p);
                if (p != NULL) return false;
            }
        }
    }
    return true;
}
```
## 7. 线索二叉树
```c
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;                    // 0 指向孩子，1 指向前驱/后继
} ThreadNode, *ThreadTree;

// 中序线索化
void InThread(ThreadTree &p, ThreadTree &pre) {
    if (p != NULL) {
        InThread(p->lchild, pre);
        if (p->lchild == NULL) {       // 左孩子为空，建立前驱线索
            p->lchild = pre;
            p->ltag = 1;
        }
        if (pre != NULL && pre->rchild == NULL) {  // 建立前驱结点的后继线索
            pre->rchild = p;
            pre->rtag = 1;
        }
        pre = p;
        InThread(p->rchild, pre);
    }
}
void CreateInThread(ThreadTree T) {
    ThreadTree pre = NULL;
    if (T != NULL) {
        InThread(T, pre);
        pre->rchild = NULL;            // 处理最后一个结点
        pre->rtag = 1;
    }
}
// 求中序序列第一个结点
ThreadNode *FirstNode(ThreadNode *p) {
    while (p->ltag == 0) p = p->lchild; // 最左下结点
    return p;
}
// 求中序序列中 p 的后继
ThreadNode *NextNode(ThreadNode *p) {
    if (p->rtag == 0) return FirstNode(p->rchild);
    else return p->rchild;              // rtag = 1，直接是后继线索
}
// 中序线索树的非递归遍历
void InOrder(ThreadNode *T) {
    for (ThreadNode *p = FirstNode(T); p != NULL; p = NextNode(p))
        visit(p);
}
```
> 求最后一个结点和后继结点的**前驱**，只需把算法中的 l 和 r 互换即可
## 8. ⭐二叉树的最近公共祖先
```c
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
	if (root == nullptr || root == p || root == q) {
		return root; // 找到 p 或 q 就不往下递归了
	}
	TreeNode* left = lowestCommonAncestor(root->left, p, q);
	TreeNode* right = lowestCommonAncestor(root->right, p, q);
	if (left && right) { // 左右都找到
		return root; // 当前节点是最近公共祖先
	}
	// 如果只有左子树找到，就返回左子树的返回值
	// 如果只有右子树找到，就返回右子树的返回值
	// 如果左右子树都没有找到，就返回 nullptr（注意此时 right = nullptr）
	return left ? left : right;
}
```
## 9. 销毁二叉树（递归释放子树）
```c
// 后序释放：先孩子、后自己（顺序不能反，否则丢失孩子指针 → 内存泄漏）
void DestroyTree(BiTree &T) {
    if (T == NULL) return;
    DestroyTree(T->lchild);            // ① 释放左子树
    DestroyTree(T->rchild);            // ② 释放右子树
    free(T);                           // ③ 释放根结点
    T = NULL;                          // ④ 置空，防野指针
}
```
> [!warning] 为什么必须后序、为什么用引用
> 删根前要先靠 `T->lchild`、`T->rchild` 找到孩子；若先 `free(T)`，孩子指针丢失 → 泄漏。
> 形参用引用 `BiTree &T`，是为了最后 `T = NULL` 能改到实参，避免调用方留下野指针。

**只释放某棵子树**（传子树根即可，函数内会把父结点那个指针置空）
```c
DestroyTree(p->lchild);    // 释放 p 的左子树，p->lchild 被自动置为 NULL

// 若要先断链再释放：
BiTree tmp = p->lchild;
p->lchild = NULL;          // 先断开
DestroyTree(tmp);          // 再释放
```

**408 变体：删除以 x 为根的子树**（其余结点保留）
```c
void DeleteXSubtree(BiTree &T, ElemType x) {
    if (T == NULL) return;
    if (T->data == x) { DestroyTree(T); return; }  // 命中即销毁整棵子树
    DeleteXSubtree(T->lchild, x);
    DeleteXSubtree(T->rchild, x);
}
```
> [!warning] 易错点
> ① 必须先删孩子再删根（后序）；② 释放后必须置 `NULL`；③ 只 `free` 根不递归 = 没释放子树。

## 1. 存储结构

### 邻接表

```c
typedef struct ArcNode {               // 边/弧结点

    // InfoType info;                  // 权值等（可选）
} ArcNode;
```

## 2. 广度优先搜索（BFS，借助队列）
```c
bool visited[MAX_VERTEX_NUM];

void BFS(Graph G, int v) {
    visit(v);
    visited[v] = true;
    EnQueue(Q, v);
    while (!isEmpty(Q)) {
        DeQueue(Q, u);
        for (w = FirstNeighbor(G, u); w >= 0; w = NextNeighbor(G, u, w))
            if (!visited[w]) {
                visit(w);
                visited[w] = true;
                EnQueue(Q, w);
            }
    }
}
void BFSTraverse(Graph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    InitQueue(Q);
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i]) BFS(G, i);
}
```
> 邻接表 $O(|V|+|E|)$，邻接矩阵 $O(|V|^2)$；调用次数 = 连通分量数（无向图）；可求**无权图单源最短路径**
## 3. 深度优先搜索（DFS，借助递归栈）
```c
bool visited[MAX_VERTEX_NUM];

void DFS(Graph G, int v) {
    visit(v);
    visited[v] = true;
    for (w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
        if (!visited[w]) DFS(G, w);
}
void DFSTraverse(Graph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i]) DFS(G, i);
}
```
## 4. 拓扑排序（Kahn 算法，邻接表 $O(|V|+|E|)$）
```c
bool TopologicalSort(ALGraph G) {
    InitStack(S);                              // 存放入度为 0 的顶点
    for (int i = 0; i < G.vexnum; i++)
        if (indegree[i] == 0) Push(S, i);
    int cnt = 0;
    while (!StackEmpty(S)) {
        Pop(S, i);
        print[cnt++] = i;                      // 输出顶点
        for (p = G.vertices[i].firstarc; p; p = p->nextarc) {
            int v = p->adjvex;
            if (!--indegree[v]) Push(S, v);    // 入度减为 0 则入栈
        }
    }
    return cnt == G.vexnum;                    // 顶点未全部输出说明有环
}
```

# 五、查找
## 1. 顺序查找（哨兵）
```c
typedef struct {
    ElemType *elem;                    // 0 号单元留空作哨兵
    int TableLen;
} SSTable;

int Search_Seq(SSTable ST, ElemType key) {
    ST.elem[0] = key;                  // 哨兵
    int i;
    for (i = ST.TableLen; ST.elem[i] != key; i--);
    return i;                          // i == 0 查找失败
}
```
## 2. 折半查找（仅适用于**有序顺序表**，$O(\log n)$）
```c
int Binary_Search(SSTable L, ElemType key) {
    int low = 0, high = L.TableLen - 1, mid;
    while (low <= high) {
        mid = (low + high) / 2;        // 全程统一取整方式
        if (L.elem[mid] == key) return mid;      // 查找成功
        else if (L.elem[mid] > key) high = mid - 1;
        else low = mid + 1;
    }
    return -1;                         // 查找失败
}
```
## 3. 二叉排序树（BST）
```c
// 查找
BSTNode *BST_Search(BiTree T, int key) {
    while (T != NULL && key != T->key) {
        if (key < T->key) T = T->lchild;
        else T = T->rchild;
    }
    return T;                          // 找到返回结点，否则 NULL
}
// 插入（新结点一定插成叶结点）
bool BST_Insert(BiTree &T, int key) {
    if (T == NULL) {
        T = (BiTree)malloc(sizeof(BSTNode));
        T->key = key;
        T->lchild = T->rchild = NULL;
        return true;
    }
    if (key == T->key) return false;   // 关键字已存在，插入失败
    else if (key < T->key) return BST_Insert(T->lchild, key);
    else return BST_Insert(T->rchild, key);
}
// 构造
void Create_BST(BiTree &T, KeyType keys[], int n) {
    T = NULL;
    for (int i = 0; i < n; i++) BST_Insert(T, keys[i]);
}
// 删除
void DeleteNode(BiTree &p) {
    if (p->rchild == NULL) {           // 右子树空，重接左子树
        BiTree q = p; p = p->lchild; free(q);
    } else if (p->lchild == NULL) {    // 左子树空，重接右子树
        BiTree q = p; p = p->rchild; free(q);
    } else {                           // 左右均不空，用直接后继替代
        BiTree q = p, s = p->rchild;
        while (s->lchild != NULL) { q = s; s = s->lchild; }  // 找最左下（后继）
        p->key = s->key;
        if (q != p) q->lchild = s->rchild;
        else q->rchild = s->rchild;
        free(s);
    }
}
bool BST_Delete(BiTree &T, int key) {
    if (T == NULL) return false;
    if (key == T->key) { DeleteNode(T); return true; }
    else if (key < T->key) return BST_Delete(T->lchild, key);
    else return BST_Delete(T->rchild, key);
}
```

# 六、排序（均为升序）
## 1. 直接插入排序（$O(n^2)$，稳定，$O(1)$）
```c
void InsertSort(int A[], int n) {
    int i, j, temp;
    for (i = 1; i < n; i++) {
        temp = A[i];
        j = i - 1;
        while (j >= 0 && temp < A[j]) {    // 从右向左找插入位置
            A[j + 1] = A[j];               // 元素后移
            j--;
        }
        A[j + 1] = temp;
    }
}
```
## 2. 折半插入排序（比较 $O(n\log n)$，移动仍 $O(n^2)$，稳定）
```c
void BinaryInsertSort(int A[], int n) {
    int i, j, low, high, mid, temp;
    for (i = 1; i < n; i++) {
        temp = A[i];
        low = 0; high = i - 1;
        while (low <= high) {              // 折半查找插入位置
            mid = (low + high) / 2;
            if (A[mid] > temp) high = mid - 1;  // 相等时取右半区，保证稳定
            else low = mid + 1;
        }
        for (j = i - 1; j >= low; j--) A[j + 1] = A[j];
        A[low] = temp;
    }
}
```
## 3. 希尔排序（缩小增量，不稳定，$O(1)$）
```c
void ShellSort(int A[], int n) {
    int d, i, j, temp;
    for (d = n / 2; d >= 1; d = d / 2) {   // 增量序列：d = n/2, n/4, ..., 1
        for (i = d; i < n; i++) {
            temp = A[i];
            j = i - d;
            while (j >= 0 && temp < A[j]) {
                A[j + d] = A[j];           // 组内元素后移
                j = j - d;
            }
            A[j + d] = temp;
        }
    }
}
```
## 4. 冒泡排序（稳定，$O(n^2)$，最好 $O(n)$）
```c
void BubbleSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool flag = false;                 // 本趟是否发生交换
        for (int j = n - 1; j > i; j--) {
            if (A[j - 1] > A[j]) {
                swap(A[j - 1], A[j]);
                flag = true;
            }
        }
        if (!flag) return;                 // 无交换说明已有序
    }
}
```
## 5. 快速排序（平均最优，不稳定，空间 $O(\log n)$）
```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];                    // 以第一个元素为枢轴
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];                  // 比 pivot 小的移到左边
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];                  // 比 pivot 大的移到右边
    }
    A[low] = pivot;                        // 枢轴归位
    return low;
}
void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pivotpos = Partition(A, low, high);
        QuickSort(A, low, pivotpos - 1);
        QuickSort(A, pivotpos + 1, high);
    }
}
```
## 6. 简单选择排序（不稳定，$O(n^2)$，移动次数最少）
```c
void SelectSort(int A[], int n) {
    int i, j, minIndex, temp;
    for (i = 0; i < n - 1; i++) {
        minIndex = i;
        for (j = i + 1; j < n; j++)        // 在无序区找最小值
            if (A[j] < A[minIndex]) minIndex = j;
        if (minIndex != i) {
            temp = A[i]; A[i] = A[minIndex]; A[minIndex] = temp;
        }
    }
}
```
## 7. 堆排序（升序用大根堆，不稳定，$O(n\log n)$，$O(1)$）
```c
// 向下调整：将以 k 为根的子树调整为大根堆（下标从 0 开始）
void HeadAdjust(int A[], int k, int len) {
    int temp = A[k];
    for (int i = 2 * k + 1; i < len; i = 2 * i + 1) {
        if (i + 1 < len && A[i] < A[i + 1]) i++;  // 取较大的孩子
        if (temp >= A[i]) break;
        else { A[k] = A[i]; k = i; }              // 较大孩子上移
    }
    A[k] = temp;
}
// 建堆：从最后一个非叶结点 len/2-1 起自下而上调整
void BuildMaxHeap(int A[], int len) {
    for (int i = len / 2 - 1; i >= 0; i--) HeadAdjust(A, i, len);
}
// 堆排序主函数
void HeapSort(int A[], int n) {
    BuildMaxHeap(A, n);                    // 建堆 O(n)
    for (int i = n - 1; i > 0; i--) {
        swap(A[0], A[i]);                  // 堆顶（最大值）换到末尾
        HeadAdjust(A, 0, i);               // 堆大小减 1，重新调整
    }
}
```
## 8. 归并排序（稳定，$O(n\log n)$，空间 $O(n)$）
```c
// 合并有序的 A[low...mid] 和 A[mid+1...high]
void Merge(int A[], int low, int mid, int high) {
    int *B = (int *)malloc((high - low + 1) * sizeof(int));
    int i, j, k;
    for (k = low; k <= high; k++) B[k - low] = A[k];  // 复制到辅助数组
    for (i = low, j = mid + 1, k = low; i <= mid && j <= high; k++) {
        if (B[i - low] <= B[j - low]) A[k] = B[i++ - low];  // <= 保证稳定
        else A[k] = B[j++ - low];
    }
    while (i <= mid) A[k++] = B[i++ - low];
    while (j <= high) A[k++] = B[j++ - low];
    free(B);
}
void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);
        MergeSort(A, mid + 1, high);
        Merge(A, low, mid, high);
    }
}
```
