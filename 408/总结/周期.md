# 408 中的"周期"汇总

> [!abstract] 一句话总览
> 408 里的"周期"其实分三大类：**① CPU 时序层级**（时钟周期 → 机器周期 → 指令周期，计组核心）；**② 存储/总线/I-O 的各类操作周期**（存取周期、总线周期、刷新周期、DMA 周期…）；**③ 协议/系统的"周期性"行为**（RIP 30s 更新、时钟中断、扫描周期…）。答题时最容易错的是**混淆层级关系**与**混用"周期/频率"倒数**。

---

## 一、⭐ 核心三级时序（计组 · 中央处理器）

> [!tip] 层级关系（必背）
> **时钟周期（节拍） < 机器周期（CPU 周期） < 指令周期**
> 一个机器周期 = 若干时钟周期；一个指令周期 = 若干机器周期。
> 公式：**指令周期 = 取指周期 + 间址周期 + 执行周期 + 中断周期**（间址、中断为可选）。

| 术语 | 定义 | 出处 |
|---|---|---|
| **时钟周期（节拍）** | CPU 时钟信号一个完整振荡周期的时间，$\text{周期}=1/\text{主频}$；最基础时序单位，所有微操作的时间基准。长度由数据通路中相邻状态单元间**组合逻辑最大传播延迟**决定 | [[408/计算机组成原理/5.中央处理器/2.指令执行过程.md]] / [[408/计算机组成原理/5.中央处理器/3.数据通路的功能和基本结构.md]] |
| **机器周期（CPU 周期）** | 完成一次**基本操作**所需的时间（一次访存读/写、一次总线传输）；通常包含若干个时钟周期 | [[408/计算机组成原理/5.中央处理器/2.指令执行过程.md]] |
| **指令周期** | CPU 取出并执行**一条指令**所需的全部时间，由若干机器周期组成 | [[408/计算机组成原理/5.中央处理器/2.指令执行过程.md]] |
| **取指周期** | 从主存取出一条指令；**每条指令必有** | 同上 |
| **间址周期** | 取操作数的**有效地址**；仅间接寻址时才有 | 同上 |
| **执行周期** | 完成指令规定的操作；**每条指令必有** | 同上 |
| **中断周期** | 响应中断、保存断点；**仅当指令执行完毕检测到中断请求**时才进入，决定中断的"异步性"（必发生在指令边界） | [[408/计算机组成原理/5.中央处理器/2.指令执行过程.md]] / [[408/计算机组成原理/5.中央处理器/5.异常和中断机制.md]] |

> [!warning] 高频考点
> - **机器周期 ≈ 一次访存**：指令执行所需机器周期数与**访存次数**密切相关。
>   - MOV（寄存器间）、ADD（寄存器）：1 取指 + 1 执行（无访存）
>   - LOAD/STORE：1 取指 + 可能 1 间址 + 1 执行（执行周期含访存）
> - 单总线数据通路中："机器周期以一次访存为界"——取指 C1~C10 共 10 拍，ADD 执行 3 拍（1 个机器周期），LOAD/STORE 执行 7 拍（2 个机器周期）。

### 处理器模型中的"周期"

| 术语 | 定义 | 出处 |
|---|---|---|
| **单周期处理器** | 每条指令在**一个时钟周期**内完成；CPI = 1；时钟周期 = **最慢指令**执行时间 | [[408/计算机组成原理/5.中央处理器/2.指令执行过程.md]] |
| **多周期处理器** | 每条指令拆成多阶段，**每阶段一个时钟周期**；同一时刻只处理一条指令。R 型 4 周期、LOAD 5 周期、STORE 4 周期、分支 3 周期 | [[408/计算机组成原理/5.中央处理器/2.指令执行过程.md]] / [[408/计算机组成原理/5.中央处理器/3.数据通路的功能和基本结构.md]] |
| **流水线周期 Δt** | 每周期启动并完成一条指令；$T_k=(k+n-1)\Delta t$ | [[408/计算机组成原理/5.中央处理器/6.指令流水线.md]] |
| **微周期（Micro-cycle）** | 执行**一条微指令**所需时间；通常 = 1 个时钟周期（控存够快时），不足时可 = 多个时钟周期 | [[408/计算机组成原理/5.中央处理器/4.控制器的功能和工作原理.md]] |

> [!note] RISC/CISC
> RISC 绝大多数指令在**一个时钟周期**内完成，CPI ≈ 1；CISC 指令执行周期数相差悬殊，属多周期。
> 出处：[[408/计算机组成原理/4.指令系统/4.CISC 和 RISC 的基本概念.md]]

## 二、性能指标中的"周期"（计组 · 计算机概述）

| 术语 | 定义 / 公式 | 出处 |
|---|---|---|
| **时钟周期 T** | 主频（时钟频率）的倒数：$f=1/T$，"每秒包含的时钟周期数"即主频 | [[408/计算机组成原理/1.计算机概述/3.计算机性能指标.md]] |
| **CPI** | 执行每条指令（平均）所需的**时钟周期数**：$\text{CPI}=\dfrac{\text{总时钟周期数}}{\text{指令总条数}}$；IPC = 1/CPI | 同上 |
| **CPU 执行时间** | $T_{CPU}=\text{指令条数}\times\text{CPI}\times\text{时钟周期}=\dfrac{\text{指令条数}\times\text{CPI}}{\text{主频}}$ | 同上 |

## 三、存储系统中的"周期"（计组 · 存储系统）

| 术语                     | 定义 / 公式                                                                                                                      | 出处                                                                      |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **存取周期 $T_M$**         | 存储器做**两次连续独立存取操作**所需的最小时间间隔；**存取周期 = 存取时间 + 恢复时间**（破坏性读出需重写/再生），故 存取周期 > 存取时间                                                | [[408/计算机组成原理/3.存储系统/1.存储器概述.md]]                                       |
| **刷新周期**               | 对某一特定行完成一次刷新后，到下一次对该行再次刷新的**时间间隔**（通常 2ms~64ms）；完整刷新一遍 = $N\times$ 存取周期                                                      | [[408/计算机组成原理/3.存储系统/2.主存储器.md]]                                        |
| **再生（重写）**             | DRAM 破坏性读出后必须立即重写（再生）；SRAM 为非破坏性读出                                                                                           | [[408/计算机组成原理/3.存储系统/1.存储器概述.md]] / [[408/计算机组成原理/3.存储系统/2.主存储器.md]]    |
| **存储带宽**               | $=\dfrac{\text{数据总线宽度}}{\text{存取周期}}$；缩短存取周期是提速手段之一                                                                          | [[408/计算机组成原理/3.存储系统/1.存储器概述.md]]                                       |
| **多体交叉的 $T$ 与 $\tau$** | 单模块**存取周期 $T$** 不变；模块**启动间隔 $\tau=T/m$**（m 体）。连续读 n 字总时间 $T+(n-1)\tau$。⚠️ 考试中"存取周期"通常指单模块 T，"总线传输周期 $\tau$"才是 T/m，**二者不可混淆** | [[408/计算机组成原理/3.存储系统/2.主存储器.md]]                                        |
| **Cache 存取周期 $t_c$**   | 命中时的 Cache 访问时间（L1 2~4 个时钟周期、L2 10~20、L3 30~50；TLB 1~2 个时钟周期；未命中代价几十~几百时钟周期）                                                 | [[408/计算机组成原理/3.存储系统/5.高速缓冲存储器.md]] / [[408/计算机组成原理/3.存储系统/6.虚拟存储器.md]] |
| **虚拟存储器未命中**           | 代价极大（磁盘访问，**百万周期量级**）                                                                                                        | [[408/计算机组成原理/3.存储系统/6.虚拟存储器.md]]                                       |

> [!warning] 两个易错点
> 1. **存取周期 ≠ 时钟周期**：存取周期是连续两次独立访存的最小间隔，远大于时钟周期（同步 DRAM 中一次行激活+预充电对应多个时钟周期）。
> 2. **分散刷新会使"存取周期变长"**（= 读写时间 + 刷新时间）。
> 出处：[[408/计算机组成原理/3.存储系统/2.主存储器.md]]

## 四、总线中的"周期"（计组 · 总线）

| 术语 | 定义 | 出处 |
|---|---|---|
| **总线传输周期（总线周期）** | 完成**一次完整总线操作**（如一次读/写）所需的时钟周期数或时间 | [[408/计算机组成原理/6.总线/1.总线概述.md]] |
| **总线周期 ≠ 时钟周期** | 同步总线上，一个总线周期由**固定个数**的时钟周期组成，该数值按**所有设备中最慢者**确定；典型读/写事务至少 2 个周期（地址周期 + 数据周期） | [[408/计算机组成原理/6.总线/2.总线事务和定时.md]] |
| **各类总线定时中的"周期"** | **同步**：总线周期长度固定；**半同步**：固定基础周期 + 慢速设备插入**等待周期 $T_w$**；**异步**：总线周期长度不固定，"时钟周期这一度量根本不成立"，由握手往返延迟决定；**分离式**：事务拆分为请求/应答两个子周期 | 同上 |
| **总线工作频率** | DDR 中时钟上、下沿各传一次，**工作频率 = 2× 时钟频率**；带宽 $=\text{总线宽度}\times\text{总线工作频率}$（多周期则再除以传输所需时钟周期数） | [[408/计算机组成原理/6.总线/1.总线概述.md]] |

## 五、I/O 系统中的"周期"（计组 + 操作系统）

| 术语 | 定义 | 出处 |
|---|---|---|
| **DMA 操作周期** | CPU 发出总线响应信号后，DMA 控制器接管总线控制权，进入 DMA 操作周期 | [[408/计算机组成原理/7.输入输出系统/3.输入输出方式.md]] |
| **周期挪用（周期窃取 / cycle stealing）** | 允许 I/O 设备**挪用（窃取）一个主存存储周期/总线周期**，传送完一个数据字后立即释放总线；最常用方式。若 CPU 正在访存，需等待当前存储周期结束 | [[408/计算机组成原理/7.输入输出系统/3.输入输出方式.md]] / [[408/操作系统/5.输入输出管理/1.输入输出管理概述.md]] |
| **交替访问（C1/C2）** | 把**总线周期/CPU 周期**分为 C1（CPU）和 C2（DMA）两半，CPU 与 DMA 分别在不同半周期交替访存，实现无冲突并行 | [[408/操作系统/5.输入输出管理/1.输入输出管理概述.md]] |
| **中断检查时机** | CPU 在**每个指令周期结束时**采样中断请求线；外部中断"在指令执行完毕后（指令周期末尾）才响应" | [[408/计算机组成原理/7.输入输出系统/3.输入输出方式.md]] / [[408/操作系统/3.内存管理/2.虚拟内存管理.md]] |
| **定时查询周期** | 程序直接控制方式下，CPU **周期性地**（每隔固定时钟周期）检查设备状态寄存器 | [[408/计算机组成原理/7.输入输出系统/3.输入输出方式.md]] |
| **显示器刷新周期** | 必须**周期性重绘**整屏图像，刷新频率 ≥ 60Hz | [[408/计算机组成原理/7.输入输出系统/1.输入输出系统基本概念.md]] |

> [!note] 中断机制补充（计组）
> **时钟中断（周期性中断）** 由可编程间隔定时器（PIT）以固定时间间隔产生，计数器自动重装，持续产生周期性中断信号（Linux 可用 NO_HZ 取消）。
> 出处：[[408/计算机组成原理/5.中央处理器/5.异常和中断机制.md]]

## 六、操作系统中的"周期"

> [!tip] 结论
> 操作系统里**字面的"周期"术语很少**，更多是"周期性行为/时间指标"。真正的周期术语是 **周期挪用、扫描周期、交替访问**。

| 术语 | 定义 | 出处 |
|---|---|---|
| **扫描周期** | CLOCK（二次机会）置换算法中，被清零的访问位给页面一个**完整扫描周期**作为"最后机会"：此期间再被访问则重新置 1，整个周期未访问则下一轮淘汰 | [[408/操作系统/3.内存管理/2.虚拟内存管理.md]] |
| **周期性回收** | 守护进程定时唤醒（如 Linux `kswapd`），**周期性扫描**内存，提前回收长时间未访问页面 | [[408/操作系统/3.内存管理/2.虚拟内存管理.md]] |
| **TLB 查找周期** | TLB 为相联存储器，可同时比较所有条目，查找**通常在一个 CPU 时钟周期内完成** | [[408/操作系统/3.内存管理/1.内存管理概念.md]] |
| **时钟中断 / 时间片** | 时钟中断发生时检查当前进程时间片是否用完；**时间片** = 进程一次最多连续占用 CPU 的时间长度，时间片到 → 调度切换 | [[408/操作系统/1.计算机系统概述/3.操作系统的运行环境.md]] / [[408/操作系统/2.进程与线程/1.进程.md]] |

> [!note] 相关但非"周期"命名的时间指标（易被问到）
> - **周转时间** = 完成时间 − 到达时间 = 等待时间 + 运行时间；带权周转时间 = 周转/运行 ≥ 1
> - **响应时间** = 首次响应时刻 − 提交时刻
> - **时间片**（轮转 RR）：时间片到后进程重新入队尾
> 出处：[[408/操作系统/2.进程与线程/3.CPU 调度.md]]

## 七、计算机网络中的"周期"

> [!tip] 结论
> 计网里的"周期"多是**协议的周期性行为**（定时器间隔）。数据结构中**没有**周期术语（只有控制流的"循环"）。

| 术语 | 定义 / 数值 | 出处 |
|---|---|---|
| **信号周期（码元宽度）** | 一个码元所占的固定时长；"用一个固定时长的信号波形表示一位 k 进制数字，该时长称为码元宽度（信号周期）" | [[408/计算机网络/2.物理层/1.通信基础.md]] |
| **停止-等待发送周期** | 每发一帧等一个 ACK，周期 $=T_D+2T_P+T_A$；每成功发一帧的代价是**完整一个 RTT 周期** | [[408/计算机网络/3.数据链路层/4.流量控制与可靠传输机制.md]] |
| **连续 ARQ 周期** | 窗口内连续发送、累积确认；**一个周期内最多发 $W_T$ 帧** | 同上 |
| **RIP 路由更新周期** | **周期性交换**路由信息，默认每 **30 秒**一次（25~35s 随机抖动避免同步）；触发更新则立即发送 | [[408/计算机网络/4.网络层/4.路由算法与路由协议.md]] |
| **OSPF LSA 刷新周期** | 按固定周期（如每 **30 分钟**）刷新，靠序号与 Age 防重复/过期；Hello 每 **10 秒**周期性发送 | 同上 |
| **BGP KEEPALIVE 周期** | 周期性发送（默认 **60 秒**），防止 Hold Timer 超时断开；BGP 仅增量更新，无需周期性交换整表 | 同上 |
| **多播成员探询周期** | 本地多播路由器**周期性探询**局域网主机，几次无响应则停止转发该组关系 | [[408/计算机网络/4.网络层/5.IP多播.md]] |
| **零窗口探测周期** | 由持续计时器**周期性发送**零窗口探测，解决零窗口死锁 | [[408/计算机网络/5.传输层/3.TCP.md]] |
| **更新周期的时间尺度** | 秒~分钟级（周期性或触发式更新），对比转发的纳秒级 | [[408/计算机网络/4.网络层/7.网络层设备.md]] |

> [!warning] 数据结构
> 数据结构目录**无"周期"术语**。出现的"循环"（循环链表、循环队列、算法中的循环）都是**控制流循环**，不构成周期性定义。

## 八、⭐ 易混淆辨析总表

| # | 容易混淆的一对 | 关键区别 |
|---|---|---|
| 1 | **时钟周期 vs 机器周期 vs 指令周期** | 层层包含：时钟 < 机器 < 指令；机器周期 = 一次基本操作（常为一次访存） |
| 2 | **存取周期 vs 存取时间** | 存取周期 = 存取时间 + 恢复时间，故 **存取周期 > 存取时间** |
| 3 | **存取周期 vs 时钟周期** | 存取周期是连续两次访存的**最小间隔**，远大于时钟周期 |
| 4 | **多体交叉：存取周期 T vs 启动间隔 τ** | 单模块 T 不变；启动间隔 τ = T/m，别把 τ 当存取周期 |
| 5 | **总线周期 vs 时钟周期** | 一个总线周期含**固定个数**时钟周期（按最慢设备定），≠ 1 个时钟周期 |
| 6 | **周期 vs 频率** | 互为倒数：$f=1/T$（主频↔时钟周期、总线工作频率↔总线时钟周期） |
| 7 | **中断周期 vs 时钟中断** | 中断周期是**指令周期的一个子阶段**；时钟中断是**周期性产生的中断源** |
| 8 | **定期 vs 触发（计网）** | RIP 周期性(30s) vs 触发更新；BGP 增量 vs 周期整表 |

---

> [!quote] 复习口诀
> **时序三级**：时钟→机器→指令，取指间址执行中断。
> **存储记周期**：存取周期含恢复，刷新周期管两遍，交叉 τ 是 T/m。
> **总线看定时**：同步定长、异步握手，周期数看最慢件。
> **I/O 抢总线**：DMA 周期挪用，C1/C2 交替访存。
> **协议定时器**：RIP 30s、Hello 10s、KEEPALIVE 60s、LSA 30min。
